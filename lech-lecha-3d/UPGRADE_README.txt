לך־לך – גרסה תלת־ממדית משודרגת (V2)

מה חדש?
• אברהם עם פנים, זקן, גלימה, תיק, ידיים ורגליים שזזות בהליכה
• מצלמה קרובה יותר, מאחורי הדמות
• מסלול מדברי מתפתל בין התחנות
• שיירות גמלים, עדרי כבשים, עצי דקל, נווה מדבר והרים ברקע
• שמיים ליליים וכוכבים בתחנת הבטחת הכוכבים
• כוכבים מונפשים בזמן תשובה נכונה

איך לעדכן את GitHub:
1. בתוך lech-lecha-3d/src החליפו את main.js ואת style.css בקבצים החדשים.
2. בצעו Commit changes.
3. המתינו לסיום Deployment ב-Vercel ורעננו את אתר המשחק.

בגרסה זו לא שינינו שאלות, תשובות או מנגנון ניקוד.
