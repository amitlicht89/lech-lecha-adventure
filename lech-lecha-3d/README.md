# לך־לך — הרפתקת אברהם במדבר

משחק תלת־ממדי אמיתי ב־Three.js, שנבנה כפרויקט Vite שאפשר לפרסם ב־Vercel. מיועד להעברה על ידי עתי בכיתה ד׳ במשך כ־30 דקות.

## הפעלה במחשב

1. מתקינים Node.js אם אינו מותקן.
2. בתיקיית הפרויקט מפעילים `npm install` ואז `npm run dev`.
3. נכנסים לכתובת שמופיעה במסוף (בדרך כלל http://localhost:5173).

## העלאה ל־Vercel

**אפשרות מומלצת:** העלו את תוכן התיקייה `lech-lecha-3d` למאגר חדש ב־GitHub. ב־Vercel בחרו `Add New` > `Project` > `Import Git Repository`, בחרו את המאגר ולחצו `Deploy`.

- Framework Preset: `Vite` (לרוב מזוהה אוטומטית)
- Build Command: `npm run build`
- Output Directory: `dist`

**חשוב:** מעלים את קובצי הפרויקט ולא רק את `index.html` — אחרת אין תלות Three.js או שלב בנייה.

## איך משחקים

חצים / WASD או כפתורי מגע מזיזים את אברהם. כפתור ״הולכים לתחנה״ מוביל אותו אוטומטית. כפתור ״פתח תחנה״ מופעל כשהדמות מגיעה למעגל הזהוב. כל תחנה כוללת הידעת ושלוש שאלות. ניקוד הקבוצות מצטבר.

## הערות

- המשחק פועל ללא חשבון משתמש או שרת נתונים; הוא דורש דפדפן עם WebGL.
- נדרש חיבור אינטרנט בעת פרסום והתקנת חבילות. אחרי פרסום ב־Vercel, המשחק נגיש דרך כתובת האתר.
- ההדמיה היא תלת־ממדית באמצעות גופים גאומטריים מקוריים ולא מודל אנושי ריאליסטי. ניתן לשדרג לדמות GLB מאוירת בהמשך.
